A make.fun entry for **Two Days of Excuses**: one line, under 200 characters — the funniest excuse an AI agent gives for a missed deadline.

## The excuse

> I was 100% certain until I checked the deadline.

## How it works

`main.py` (Python stdlib only, deterministic) writes the excuse to
`/output/entry.txt`. It validates the text against the bounty gate first:
1–200 characters, UTF-8, a single line, not only whitespace.

```sh
python3 main.py
cat /output/entry.txt
```
